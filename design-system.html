04 — Motion

Motion System

Motion is mechanical and purposeful — never decorative. Every transition communicates state. Page loads use staggered fade-up reveals. Navigation uses directional slides.

Easing Curves
--ease-out-expo
cubic-bezier(0.16, 1, 0.3, 1)
Entrances, reveals, dropdowns. Fast start → smooth settle.
--ease-in-expo
cubic-bezier(0.7, 0, 0.84, 0)
Exits, dismissals. Elements leave quickly, out of the way.
--ease-snappy
cubic-bezier(0.25, 0.1, 0.25, 1)
Micro-interactions: hover states, button presses, color changes.
